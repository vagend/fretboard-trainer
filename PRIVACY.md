# Privacy Policy

This privacy policy explains how the `fretboard-trainer` project handles
user data.

## Summary

`fretboard-trainer` is a browser-based guitar learning tool. It is designed
to run without a backend service or user account system.

## Microphone access

The microphone feature is only used when the user explicitly starts the
"Play it (mic)" mode or the tuner mode. When enabled, audio is processed
locally in the browser with the Web Audio API.

This project does not send microphone audio to a remote server or a
third-party service.

## Local data storage

The app may store local preferences and practice tracking data in the
browser's local storage. This can include:

- Selected note names and tuning preferences
- Microphone and device settings
- Score, streak, and practice history

This data remains on the user's device unless the browser data is cleared.

## Third-party services and tracking

This project does not currently use third-party analytics, advertising,
cookies, or tracking services. No data is sent to a remote server for
telemetry or ad targeting.

## Data retention and user control

Local settings and progress data are retained only as long as the browser
stores them. Users can clear this data through their browser settings or
site storage controls.

Users can choose whether to allow microphone access when the browser asks
for permission. If microphone access is denied, the app can still be used
in non-microphone modes.

## Contact

If you have questions about this privacy notice or the app's data handling,
please open an issue in this repository.
