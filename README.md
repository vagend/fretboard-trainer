# fretboard-trainer

A browser-based guitar fretboard note trainer with microphone listening
and tuner modes.

## Development

This code was developed using Claude and Copilot.

## Privacy

This app uses the microphone only when the user starts the mic or tuner
mode. Audio is processed locally in the browser.

The app stores local settings and practice stats in browser storage on the
user's device. It does not use a backend, account system, cookies, or
third-party tracking.

See [PRIVACY.md](PRIVACY.md) for the full privacy policy.
